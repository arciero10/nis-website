# NIS — Sito definitivo Next.js / React

Pacchetto di handoff per lo sviluppatore della Nazionale Italiana Sanitari.

## Avvio
```bash
npm install
npm run dev
```

## Stack
- Next.js App Router
- React
- TypeScript
- CSS globale senza framework UI
- next/image
- nessuna dipendenza UI esterna
